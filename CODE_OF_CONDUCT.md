# Code of Conduct

Project participation must remain professional, constructive, and focused on the technical work. Treat contributors with respect regardless of background or experience. Harassment, threats, discriminatory conduct, sexualized attention, doxxing, and sustained disruption are not accepted.

Give actionable feedback, assume honest mistakes, and move contentious technical decisions to evidence and documented tradeoffs. Maintainers may edit or remove contributions, restrict participation, or ban participants when necessary to protect the community.

Report conduct concerns privately to the maintainers through an appropriate private GitHub channel. Do not include vulnerability details in conduct reports; use the process in [SECURITY.md](SECURITY.md).
