# Security policy

UnnamedOS Core is experimental and has not yet received an independent security audit. Do not rely on it for production or sensitive workloads.

Report suspected vulnerabilities privately through this repository's GitHub **Security** tab using **Report a vulnerability** / Private Vulnerability Reporting. If that control is unavailable, use a private GitHub Security Advisory draft addressed to the repository maintainers. Do not disclose vulnerabilities in public issues, discussions, or pull requests.

Include the affected revision, reproducible conditions, expected impact, and any suggested mitigation. Maintainers will acknowledge the report through GitHub's private advisory channel and coordinate disclosure there. No fixed response or remediation deadline is promised at this project stage.
